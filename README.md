# 西安科技大学课表

把学校教务系统的课表导入手机：可以登录学校统一认证后直接读取，也可以导入教务系统导出的 PDF。
导入后平时完全离线查看：今天上什么、下一节在哪间教室、这周是不是单周。

> **适用范围**：仅适配**西安科技大学**（统一认证 + 正方教务系统）的课表。
> 其他学校、其他版式的课表解析不了 —— 换一所学校等于换一套系统，需要另写适配。

## 功能

- **在线导入** — 登录学校统一认证网页后，点「课表查询页」自动通过正方 CAS 进入课表页，
  再点「识别导入」直接读取课表数据；不需要手动下载、传输 PDF。App 不保存账号密码。
- **本地 PDF 导入** — 也可以选教务系统导出的课表 PDF，自动解析课程名、周次、节次、教室、教师。
- **今天** — 全天时间轴：当前课程、下一节课、起止时间；已经上完的置灰。
- **课表** — 整学期网格，逐周切换；单双周正确区分，本周生效的课高亮、其余置灰。
- **编辑** — 点任意格子新增、修改、删除课程；每节课的作息时间也能改。
- **自定义高亮色** — 每门课单独设色：推荐 DeepSeek 蓝 / Claude 橙 / 雾粉，
  也可以自由调色相、深浅；默认按课名自动取色。
- **上课提醒** — 每节课开始前 12 分钟发系统通知，显示课程名、时间、地点；
  点通知回到课表。可在设置里关闭。
- **课表行高** — 设置页可调，一屏能多看几节。
- **其他课程** — 教务系统里没有固定上课时间的课程单独展示。

## 使用

### 第一次使用

1. 到「设置」确认学期名称、开学第一周周一、学期总周数
2. 到「课表」页右上角 `＋` 导入课表
3. 每节课的作息时间可以在课表页点左侧时间栏修改

### 从教务系统导入

1. 点「课表」页右上角 `＋` → 「从教务系统导入」
2. 在学校统一认证网页输入学号、密码（登录完全在学校网页上进行）
3. 点「课表查询页」；App 会通过正方 CAS 自动登录，登录后自动打开课表页
   - 学校服务器较慢时加载需要几秒，请耐心等待
4. 页面上出现课表后点「识别导入」

换账号时点导入页右上角「切换账号」，会清掉两边的登录态重新登录。
正方是单端登录，同一账号在多台设备同时登录可能被踢，重新登录一次即可。

### 本地 PDF 导入

点 `＋` → 「选择本地 PDF」，在系统文件选择器里选中教务系统导出的课表 PDF。

### 自定义高亮色

点任意课程卡片 → 在候选课弹窗里点「自定义高亮颜色」→ 选推荐色或自由取色。
新建/编辑课程的表单里也有同样的入口；选「自动」恢复按课名取色。

### 上课提醒

到「设置」打开「上课前 12 分钟提醒」。Android 13 及以上首次使用会请求通知权限。
部分手机的省电策略可能延迟提醒，建议在系统设置里允许本应用后台运行 / 自启动。

### 课表行高

到「设置」→「课表显示」拖动滑块，调小后一屏能看到更多节。

## 隐私与权限

- 课表只存在应用私有目录的 JSON 里，不导出、不上传、不统计
- **不保存账号密码**：登录在学校网页里完成，App 只保留学校网站的登录会话
  （切换账号可清空）
- 网络只访问学校域名：`*.xust.edu.cn` 与 `59.74.174.150`
- 权限只有这些，均用于对应功能：
  - `INTERNET`：在线导入
  - `POST_NOTIFICATIONS`：上课提醒
  - `RECEIVE_BOOT_COMPLETED`：重启后重新排提醒
  - `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM`：准点提醒
- 测试样本里的姓名、学号等是虚构脱敏值，只用于解析测试

## 已知限制

- 只适配西安科技大学；学校系统改版可能导致在线导入或 PDF 解析失效
- 学校服务器较慢时，登录/打开课表页需要几秒
- 正方是单端登录，多设备同时登录会互踢
- 上课提醒依赖系统通知与省电策略，个别手机可能延迟
- 个人项目，与西安科技大学官方无关

## 构建

需要 Android Studio，或 JDK 17+ 与 Android SDK 36（compileSdk 36.1）。

```bash
./gradlew assembleDebug     # 构建 debug 包
./gradlew installDebug      # 装到已连接的设备 / 模拟器
./gradlew test              # JVM 单元测试
```

Release 签名读根目录的 `keystore.properties`（该文件与 `/keystore/` 都已 gitignore）。
没有它时 debug 构建照常可用。

## 测试

```bash
./gradlew test                      # 数据、解析、颜色、提醒排期的 JVM 单测
./gradlew connectedAndroidTest      # 真实 PDF 走一遍 PDFBox + 弹窗交互
```

仓库里的 `app/src/androidTest/assets/sample-timetable.pdf` 是脱敏后的样本，
姓名、学号、教师名、专业与校区均为虚构值，布局、坐标、字体与折行位置与原文件一致。

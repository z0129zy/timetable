# v2.1 — 在线导入 · 自定义高亮色 · 上课提醒

发布日期：2026-11-28
适用：西安科技大学（统一认证 + 正方教务系统），Android 8.0+

## 本次更新

### 新增

- **从教务系统在线导入**：登录学校统一认证后，点「课表查询页」自动通过正方 CAS
  进入课表页，再点「识别导入」直接读取课表数据；不再需要手动下载、传输 PDF。
  App 不保存账号密码，登录完全在学校网页上完成。
- **每门课自定义高亮色**：推荐 DeepSeek 蓝 / Claude 橙 / 雾粉，也可自由调色相与深浅；
  深色底自动切白字，选「自动」恢复按课名取色。
- **上课前 12 分钟提醒**：系统通知栏显示课程名、时间、地点，点击回到课表；
  可在设置里关闭。
- **课表行高调节**：设置页滑块，一屏能多看几节。

### 优化

- 去掉启动页，打开即用
- 导入页增加步骤提示条，并提示学校服务器较慢、请耐心等待
- 页面加载时顶部显示进度条，加载期间禁用按钮，避免重复点击
- CAS 登录后不再等正方主菜单整页加载，URL 一变到主菜单就立刻打开课表页
- 卡片文字颜色按底色深浅自动切换，保证可读

### 修复

- 修复暖灰课程色与「非本周」灰同色，导致本周课程看起来不高亮的问题

### 移除

- 移除「关于开发者」入口与个人收款码

## 升级说明

- 从 v2.0 覆盖安装即可，课表数据保留（同一签名、versionCode 4）
- Android 13+ 首次启动会请求通知权限（用于上课提醒）
- 在线导入需要联网，并使用你自己的学校账号；App 不保存密码
- 从旧版本升级后，原 PDF 导入的课表可以继续使用；也可以重新在线导入

## 已知限制

- 仅适配西安科技大学；学校系统改版可能导致在线导入或 PDF 解析失效
- 学校服务器较慢时，登录/打开课表页需要几秒
- 正方是单端登录，同一账号多设备同时登录会互踢
- 上课提醒依赖系统通知与省电策略，个别手机可能延迟

## 隐私

- 课表只存在本机，不导出、不上传、不统计
- 不保存账号密码；只保留学校网站的登录会话（切换账号可清空）
- 网络只访问学校域名（`*.xust.edu.cn`、`59.74.174.150`）
- 权限：INTERNET、POST_NOTIFICATIONS、RECEIVE_BOOT_COMPLETED、
  SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM，均用于对应功能
